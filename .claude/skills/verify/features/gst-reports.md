# GST sales report and exports

The GST Sales report lists a tenant's non-void invoices for one month with taxable value, GST split into IGST, CGST and SGST, and a GSTR-1 section per row. A tenant can download it as a spreadsheet (CSV), an HSN/SAC summary CSV, and a PDF.

## Sub-features

- `gst-register` shows the month's invoices and totals for the tenant only.
- `gst-filter` searches by invoice, customer or GSTIN and switches the month.
- `gst-csv` downloads `gst-sales-<month>.csv`.
- `gst-hsn-csv` downloads `gstr1-hsn-summary-<month>.csv`.
- `gst-pdf` downloads `gst-sales-<month>.pdf`.
- `gst-split` classifies each invoice as intra-state (CGST plus SGST) or inter-state (IGST) from seller and client state.

## How to get to it (user POV)

- Open `Reports` then `GST Sales` (route `/reports/gst-sales`, heading `GST Sales`, table heading `GST invoice register`).
- Choose `Download spreadsheet` or `Download PDF report` on the page.
- API used by the page: `GET /api/reports/gst?month=YYYY-MM` with `format=csv`, `format=hsn-csv` or `format=pdf`, and `GET /api/gst/supply`.

## Driving it with control-billing

Preconditions:

- `control-billing doctor` reports `ok: true` and you ran `control-billing login nexio-admin`.
- Seeded invoice `NEX-2026-001` is dated 2026-10-01, so use month `2026-10`. Invoices created during a run are dated by you, so pass their month.

- **Register.** Run `control-billing snapshot /reports/gst-sales --wait-text "GST invoice register" --out gst/register.aria.txt`. The combobox `GST report month` defaults to the machine's current month, and the rows list `NEX-2026-001`.
- **Totals.** Select `2026-10` in `GST report month`. Each article labelled `Taxable value` shows a strong amount matching `₹[\d,]+\.\d{2}`. `control-billing api GET "/api/reports/gst?month=2026-10"` returns `totals.taxableMinor` equal to the sum of `items[].taxableMinor`.
- **Spreadsheet.** Run `control-billing api GET "/api/reports/gst?month=2026-10&format=csv" --out gst/gst-sales-2026-10.csv`. The header row is `Invoice number,Invoice date,Customer,Customer GSTIN,Taxable value,GST,Invoice total,IGST,CGST,SGST,Net GST,Section`, and a `Total` row closes the file. In the UI the link `Download spreadsheet` saves `gst-sales-2026-10.csv`.
- **HSN summary.** Run `control-billing api GET "/api/reports/gst?month=2026-10&format=hsn-csv"`. It is empty of data rows unless an invoice in the month has lines with an `HSN/SAC` code.
- **PDF.** Run `control-billing api GET "/api/reports/gst?month=2026-10&format=pdf"`. The result has `contentType: application/pdf`, a `contentDisposition` naming `gst-sales-2026-10.pdf`, and a saved file with its sha256. In the UI the link is `Download PDF report`.
- **Month validation.** Run `control-billing api GET "/api/reports/gst?month=2026-13"`. The status is `400` with `Choose a valid report month.`
- **Tenant isolation.** Run `control-billing api GET "/api/reports/gst?month=2026-10" --as evo-admin`. No item has an `NEX` invoice number.
- **Seller GST setup.** Save a seller GSTIN in `Company Settings` (see settings), create an invoice for a customer whose state matches or differs, and read `snapshot.documentType`, `snapshot.taxSplit` and the row's `Section` again. A matching state gives `Tax Invoice` with `intra` and CGST plus SGST. A different state gives `inter` and IGST.
- **Proof.** Save the CSV file, the register screenshot (`control-billing screenshot /reports/gst-sales gst/register.png --wait-text "GST invoice register"`) and the API JSON with `--out`. They show the month, invoice numbers and totals.

## Gotchas

- With no seller GSTIN every invoice is a `Bill of Supply`, and the register labels its rows `NIL_EXEMPT_NON_GST` even when GST was typed. Observed in this instance for `NEX-0003` (18 percent entered, `Bill of Supply` issued). Set the seller GSTIN before proving B2B or B2C sections.
- The month list is generated from the machine clock, so the default month changes with the date. Pass `month` explicitly.
- Void invoices are excluded from the report. Create-then-void changes the totals.
- GSTINs are validated with a check digit. `29AAGCB7383J1Z4` (Karnataka) and `27AAPFU0939F1ZV` (Maharashtra) are valid test values.
- The PDF is generated by the app's own writer, so judge it by name, type and a non-empty sha256, not by rendering it in a browser.
